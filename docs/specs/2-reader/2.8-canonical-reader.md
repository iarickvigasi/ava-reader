# Canonical reader candidate

> Implementation in progress · 2026-09-29 · Parent: [\_overview](_overview.md)

The v3 client preserves the accepted canonical Book graph and projects only the active chapter
and its neighbours into reader blocks. Cold targets resolve from that full graph before the
visible chapter changes. The authenticated API now checks owned publication and registered
schema/build qualification before delivering that graph; the production qualification catalog
remains empty until the actual accepted-reader evidence is complete. Validated AVA EPUB reimports
use a separate owned import/acceptance record and a newly minted final identity; they cannot import
PDF job authority or fall back to lossy legacy parsing after acceptance.

## Content and identity

- Complete nested TOC, exact prose, captions/credits, literal code/verse and source evidence remain
  paired to `final_content_id`. Text is never cleaned or normalized by the renderer.
- UTF-16 maps translate canonical code-point offsets to browser positions; split surrogate offsets
  are refused. Table cells and list leaves keep their own stable addressable block IDs.
- Finite styles preserve false/zero, family, alignment, spacing, emphasis, scripts and small caps.
- Nested lists preserve start and optional `marker_style`: decimal, lower/upper alpha, lower/upper
  Roman, or bullet. Omission preserves old semantics and old canonical document hashes.
- Tables expose row/column header relationships. Figure geometry, alt text and caption associations
  remain explicit. Owned asset URLs are fetched with authentication and verified against length
  and digest before use; verified bytes are retained with the same offline package.
- The selected resource ceiling is 200 MiB per book. This is an enforced ceiling, not evidence that
  a phone can decode/cache a book of that size; that capacity test remains required.

## Navigation and reading

TOC, notes, annotations and typed internal links request exact targets. A jump records its origin
only when the measured target is restored. Back consumes only the successfully returned entry;
failed/superseded/no-op requests add none. Textless figures remain valid zero-offset targets.
A failed visible jump keeps recovery pending until its exact origin is measured again; it never
claims the place was kept before restoration is confirmed. Repeated same-place actions do not
dispatch another restore. Notes distinguish the actual initiating reference from
the other references sharing a note. Back is session-scoped to account/book/fixed-content identity.

Canonical chapters and explicit history jumps render with standalone measured geometry, avoiding
legacy cross-chapter prefix skipping. Note and jump controls reserve stable layout, including while history is empty, so settlement
does not resize and replace the focused passage. Reflow keeps the landed
passage; ordinary page turns release that exact origin without adding history. Progress locates
table cells rather than the textless whole-table wrapper. Browser Back and persisted resume remain
separate systems. Unknown or unavailable requested chapters cannot silently substitute chapter one.

Offline storage retains the full package, verified assets and complete spine. Cached cold chapters
project locally; missing chapter rows fail closed rather than claiming a partial download readable.
Canonical bilingual mode uses final-content-bound source catalogs, preserves cell/list identity,
and refuses mismatched translation caches. Literal code is copied without AI generation.
[Canonical translation behavior and remaining evidence](../9-bilingual-mode/9.5-canonical-pdf.md).

## Evidence boundary

Synthetic source fixtures and code tests exercise conservation, resource refusals, offline identity
and history rules. A development fixture uses the real ReaderScreen but has no imported library
item or publication authority. CUA has exercised cold shared-note/Return, narrow reflow and TOC Back;
these observations do not qualify the full PDF upload, accepted delivery, annotations, native
iPhone/Android selection, accessibility, or largest supported books.

The compiled source fingerprint is reproducible but conveys no test result by itself. Server-side
registration requires independent evidence for the exact build, adapter and schema.
[Runnable checks and remaining gates](../../pdf-reader-checks.md).

Preparing bilingual source previews cannot settle the final jump. Selecting the current passage restores keyboard focus without navigating or adding history.
