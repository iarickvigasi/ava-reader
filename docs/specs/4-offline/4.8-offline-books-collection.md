# Offline Books collection (retired)

> Status: retired · Updated: 2026-10-25 · Related: [[3-library/3.1-library-screen]],
> [[3-library/3.3-collections]], [[4.2-save-sync]], [[4.3-save-button]]

The Offline Books default collection is removed together with Imported Books and Public Domain.
The migration removes only system collection rows and their membership links; it preserves books,
custom collections, offlineRequested, and device caches. Dexie v6 deletes the retired system
collection rows and their membership links atomically when each user's database opens, including
fully offline starts. It also removes their references from cached Home summaries and book-info
memberships. Custom namesakes and all pending mutations remain intact; no content cache is reset.

Saving or releasing a book offline updates intent and device content only. It never creates a
collection or changes custom membership or placement in the general Library grid. Metadata priming
and content reconciliation enumerate Library books directly, including when there are no collections.
