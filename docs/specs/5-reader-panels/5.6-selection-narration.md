# Selection narration

The selection action reads the selected word/phrase through AVA's server-funded OpenRouter key,
using Google Gemini 3.8 Flash TTS for the requested local trial. Readers supply no key, credits or payment. This exception does not
change billing plans for other AI features. A context-aware helper identifies the fragment’s language
and names that language in delivery instructions, requesting slower, clear, natural articulation.
Use Kore voice and PCM output wrapped as browser-playable WAV (24 kHz, mono, signed 16-bit LE).
Keep input literal and delivery instructions separate; do not forward other providers’ settings.
NARRATE-11: Request fully articulated final sounds and a natural completion. Preserve generated
speech samples and append 400 ms of silence before playback ends; do not fade out final phonemes.
Do not force the book language onto foreign words or translated selections. Audio quality needs
human listening evidence; delivery tags are guidance, not guaranteed phoneme timing.

Narration is ephemeral playback, not a saved comment or user-data mutation. It requires connectivity;
offline/error attempts show localized feedback and can be retried explicitly. Never replay sound
unexpectedly on reconnect. Waiting includes token acquisition, generation and audio buffering;
playing begins on the media playing event. Stop/end reset playback; selection changes, panel close
and unusable-audio failures release media. A gesture-required rejection keeps audio for direct
next-tap playback. Replaying the same selection reuses audio within the mounted panel.
The server checks authentication and library ownership before calling the provider, caps text at
2,048 characters and bounds provider wait time. It returns WAV without caching private text publicly.
See [the task](../../09-work/items/2026-10-31-word-narration.md) for evidence and limits.

## Acceptance requirements

- NARRATE-01: Exact selected words/phrases receive multilingual, clear, deliberately paced speech.
- NARRATE-02: AVA funds speech using its server OpenRouter key; no reader billing or key.
- NARRATE-03: Waiting, playing and stopped states reflect media lifecycle; active controls cancel/stop.
- NARRATE-04: Failures recover on explicit retry; selection/account/panel changes release resources.
- NARRATE-05: Server authentication, ownership and input limits precede provider usage.

Implementation is a branch candidate, not a release claim. Human listening and physical-device
qualification remain pending; automated and live-provider evidence is recorded in the task.

## Contextual language identification

NARRATE-06: Capture the containing sentence(s) for a selected word, phrase or sentence. Identify
that fragment’s intended pronunciation language, not the majority language of the book/sentence.
A kanji in Japanese prose must resolve to Japanese; a French quotation in English prose may resolve
to French. Book language or translated-column language is a weak hint, never an unconditional rule.

Use a local kana-only-selection fast path, then a bounded OpenRouter Jev 1.14 choice decision over
supported speech languages. Detect only on narration intent; coalesce/cache
identical account + fragment + context + hint decisions for ten minutes, up to 256 entries.
NARRATE-10: Use the highest-scoring supported language, regardless of absolute score or margin.
The model must choose a supported language even for ambiguous or multilingual fragments; do not
offer unknown/mixed as choices. Prefer its chosen language when valid scores tie. An empty/all-zero
supported score set is a provider failure, not a confidence rejection. Scores are not calibrated
accuracy estimates. Each detector attempt is bounded at five seconds.
Context is private request data, not a persisted annotation. Only the fragment is spoken.
Language identification cannot guarantee the correct Japanese reading or homograph stress.

## Reported pronunciation and playback fixes

NARRATE-07: Japanese kanji is converted to spoken kana by a bundled, lazily loaded Kuromoji
Japanese dictionary. Tokenize the surrounding sentence and use kana suffix/prefix alignment for partial tokens.
Unresolved partial compounds request the whole word instead of guessing an isolated reading. No book-specific title/name replacements are used.
The founder confirmed the generated 芥川龍之介 pronunciation on 31 October 2026. Dictionary readings
can still be ambiguous for unknown names or partial compounds; do not claim universal accuracy.

NARRATE-08: A browser gesture rejection retains the prepared audio and shows “tap to play”, not a
connection error. Authentication, provider failure, timeout, uncertain language and media/network
failure have separate localized feedback. Log only stage, error type and upstream status; exclude
private selection text, credentials and upstream response bodies.
Delivery instructions guide pacing; subjective pronunciation and naturalness need listening.

The completed translation speaker shares this lifecycle (see [Toolbox](5.2-ai-toolbox.md)); known
non-Latin output language is reused when script agrees, while Latin/preserved names use source/book
context. Source selections always use contextual detection. Text over
2,048 characters is unavailable with explicit feedback; a new clip stops any other active clip.

NARRATE-09: Automatically retry a timed-out language decision once, within the same coalesced
request; at most two five-second attempts. Keep loading through recovery. Do not retry malformed
decisions, configuration/auth failures, cancellation or speech generation automatically. On exhausted
retries expose the timeout and retain explicit retry. Never replace uncertainty with a book-language
guess or autoplay after cancellation. Recovery diagnostics exclude private text and credentials.
A disconnected response must not start speech after detection; the shared bounded decision may
finish/cache for other callers.
