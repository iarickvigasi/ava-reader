# Search in book

> Status: shipped · Updated: 2026-10-26 · Code: apps/web/features/reader/search,
> apps/web/components/app/reader/overlays/search

## Summary

Find and revisit a passage without leaving the reader, online or offline.

## Scope

- In: original-text word, phrase, and sentence search; sentence cards; chapter labels; navigation.
- Non-goals: fuzzy search, translated-text search, page numbers, persisted indexes or search
  history.

## Behaviour

1. Search is a peer reader panel, available on desktop and mobile in both reading modes.
2. Match case-insensitively, ignoring repeated whitespace; single words match whole words. Phrases
   and full sentences match literally, preserving punctuation and accents.
3. Show each matching sentence once per location, in book order, emphasizing every match. Headings
   and list items without punctuation are searchable text units; images are excluded.
4. A result shows the complete sentence and chapter name. Click closes the panel and navigates to
   the match. Arrival temporarily emphasizes the sentence for one second, then removes the emphasis
   over two seconds without creating a saved highlight.
5. Keep the query while reopening the panel in the same book. Another book resets search.
6. Search cached chapters progressively; show incomplete coverage until the book cache is complete.
   Empty queries explain that results will appear here. Distinguish no matches, pending searches,
   incomplete coverage and storage failures; announce coverage accessibly.
7. Opening search uses the existing reader panel/navigation transition.
8. Search can be cleared with an accessible action; clearing resets results.
9. Show a sentence count only for successful nonempty results; hide it for pending, empty and failed
   searches.

## Data & sync

Read existing chapter blocks through the book bucket. No new persistent index, mutations, or API.
Keep original UTF-16 offsets for locators, including list-item offsets without inserted separators.

## Acceptance criteria

- [x] Formatting, Unicode case, whitespace, and list offsets preserve exact navigation anchors.
- [x] Results outside the current chapter window navigate in both reading modes.
- [x] The temporary highlight starts after arrival, holds for one second, fades over two seconds,
      and never saves a highlight.
- [x] Cache arrivals refresh results; incomplete offline coverage is never presented as full-book
      search.
- [x] Keyboard activation, clear, Escape, and localized empty/error states work.

## Known gaps

Full cache coverage follows existing book-cache chapter metadata; source chapters absent from that
metadata cannot be proven present. Existing download enumeration is owned by offline reading.
