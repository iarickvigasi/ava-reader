# Search in book

> Status: shipped · Updated: 2026-10-26 · Code: apps/web/features/reader/search,
> apps/web/components/app/reader/overlays/search

## Summary

Find and revisit a passage without leaving the reader, online or offline.

## Scope

- In: original-text word, phrase, and sentence search; sentence cards; chapter labels; navigation.
- Non-goals: fuzzy search, translated-text search, page numbers, persisted indexes or search history.

## Behaviour

1. Search is a peer reader panel, available on desktop and mobile in both reading modes.
2. Match case-insensitively, ignoring repeated whitespace; single words match whole words.
   Phrases and full sentences match literally, preserving punctuation and accents.
3. Show each matching sentence once per location, in book order, emphasizing every match.
   Headings and list items without punctuation are searchable text units; images are excluded.
4. A result shows the complete sentence and chapter name. Click closes the panel and navigates
   to the match. Once visible, the sentence uses the saved-highlight yellow (mimosa) color and
   stays fully visible for one second, then fades to transparent over two seconds, keeping the
   book text readable.
5. Keep the query while reopening the panel in the same book. Another book resets search.
6. Search cached chapters progressively; show incomplete coverage until the book cache is complete.
   Empty queries show “Search results will appear here” centered in the results area. No matches,
   pending searches, and storage errors use the same centered placeholder; coverage is announced
   accessibly without helper text below the input.
7. Match other left reader panels: transparent desktop surface, translucent mobile gradient,
   shared padding and entry animation, soft-tone search input with an accessible hidden label.
   Opening search runs the existing navigation/AVA header transition.
8. All app search inputs reuse the shared search field. Its focus ring uses the muted brown theme color
   and paints inside the input so panel overflow cannot clip its sides.
9. Search, Highlights, and AI Comments share a centered panel placeholder with 20% message padding.
10. Clear search with the themed native control inside the input; no external Clear button.
11. Show the sentence count below the input only after a successful search with positive results;
    hide it for empty queries, pending searches, errors, and zero results. Always reserve its row
    height to prevent results shifting. Use the header/search-placeholder UI font, uppercase,
    and wide letter spacing.

## Data & sync

Read existing chapter blocks through the book bucket. No new persistent index, mutations, or API.
Keep original UTF-16 offsets for locators, including list-item offsets without inserted separators.

## Acceptance criteria

- [x] Formatting, Unicode case, whitespace, and list offsets preserve exact navigation anchors.
- [x] Results outside the current chapter window navigate in both reading modes.
- [x] The temporary highlight starts after arrival, holds for one second, fades over two seconds, and never saves a highlight.
- [x] Cache arrivals refresh results; incomplete offline coverage is never presented as full-book search.
- [x] Keyboard activation, clear, Escape, and localized empty/error states work.

## Known gaps

Full cache coverage follows existing book-cache chapter metadata; source chapters absent from that
metadata cannot be proven present. Existing download enumeration is owned by offline reading.
