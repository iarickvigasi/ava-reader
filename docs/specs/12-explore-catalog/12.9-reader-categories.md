# Explore · reader categories and discovery filters

> Status: active · Updated: 2026-10-24 · Parent: [\_overview](_overview.md)

## Evidence and proposal

Open Library exposes genres, subjects, people, places, and periods, with inconsistent labels and
synonyms. Its [subjects browser](https://openlibrary.org/subjects) provides useful starting groups;
these are not an exhaustive, clean classification of every work. AVA retains raw labels and derives
reader categories from explicit mappings.

Use several independent dimensions, not one category per book. A work can be fantasy, adventure,
and children's fiction together. Keep editions/languages/readable assets separate from work topics.
Unknown classification must remain unknown; absence of a fiction tag does not mean nonfiction.

| Dimension           | Suggested values                                                                                             | Evidence needed                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| Broad type          | Fiction, Nonfiction                                                                                          | Recognized source subjects/classifications or curator assertion            |
| Fiction genres      | Fantasy, Science fiction, Mystery & thriller, Romance, Historical, Horror, Adventure, Humor                  | Normalized genre tags                                                      |
| Nonfiction subjects | History, Biography & memoir, Philosophy, Psychology, Science, Technology, Business, Arts, Languages, Ecology | Normalized subject tags                                                    |
| Form                | Novel, Short stories, Poetry, Drama, Essays, Comics                                                          | Structured form/genre evidence                                             |
| Audience            | Children, Young adult                                                                                        | Explicit source audience tags; never assume Adult when missing             |
| Language            | English, Ukrainian, etc.                                                                                     | The selected/matching edition's language                                   |
| Availability        | Available to read in AVA                                                                                     | Approved processed edition asset, or later a batched personal-copy overlay |

## Current pill contract

Show Available to read, Fiction, Nonfiction, Fantasy, Novels, Short stories, Poetry, Essays,
Mystery & thriller, History, Philosophy, Science, Biography, Children, and Young adult.
Desktop uses one horizontally scrolling row; mobile uses two independently scrolling rows.
Hide scrollbars while preserving horizontal scrolling and keyboard access.
Languages use a separate single-line scrolling row on desktop and mobile, with no visible scrollbar.
Category selections combine with OR; availability and language
combine with AND, matching the same edition. Unknown classifications remain visible without filters.
Store derived category keys, raw subject labels, and rule version on works. Versioned conservative
rules recognize source labels; no fiction/nonfiction inference from missing tags. GIN indexes serve
category filtering. Mappings cover explicitly reviewed labels; unsupported languages and compounds remain unknown.
Reprocess retained raw records to enrich existing works without downloading again.

## Whole-corpus normalization plan

1. During ingestion, extract raw subjects plus subject_people/places/times with source/revision.
   Keep originals and unsupported labels; processing remains streaming and bounded.
2. Introduce stable Topic IDs with kind, parent, and localized labels; map source label aliases to
   them through versioned deterministic rules. Normalize Unicode/case/spacing without deleting
   meaningful distinctions. For Alice, map known fantasy/adventure/juvenile tags to several topics.
3. Retain WorkTopic assertions with source mapping, rule version, confidence, and review state.
   Curator decisions override automated suggestions; ambiguous or unmapped tags stay unclassified.
4. Backfill in bounded workers. Index (topicId, workId); feed topic changes through the catalog
   outbox. Rule changes rebuild derived assertions without modifying content or private uploads.
5. Measure classified coverage, conflicts, and precision by language against curated examples.
   Launch only useful categories with adequate coverage; default browsing always includes unknowns.

The richer Topic/assertion model remains future work; initial categories use versioned rules.

## Production matching and rebuild

Match complete labels after NFKC, case, apostrophe, and whitespace normalization. Never split
compound labels into keywords. “Fantasy fiction, history and criticism” remains unmapped, while
“Fantasy fiction” maps to Fiction and Fantasy. Independent supported labels still contribute.
Use explicit audience/form aliases; do not infer Nonfiction from missing Fiction.
Regression examples cover false positives, overlapping genres/audiences, and supported languages.
Rebuild existing works from retained subjects in bounded transactions with optimistic revision
checks and matching outbox events. Dry-run reports counts and examples before applying. No legacy
substring matcher or local-upload migration is retained. Rich Topic/curator assertions remain later work.
