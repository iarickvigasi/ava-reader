# Explore · browsing and shared book details

> Status: active · Updated: 2026-10-25 · Parent: [\_overview](_overview.md)

## Goal and current gaps

Explore browses canonical works with immediate filters, search, and pagination. Library and Explore
compose shared book presentation independently. Book/edition details and author pages are
implemented; personal saves and upload links remain later milestones. Reading assets follow
[12.8](12.8-reading-assets.md).

## Explore and navigation

- `/app/explore`: search title, author names/aliases, or ISBN; language filter; paginated results.
  Empty query browses all canonical works through bounded pages, without recommendations.
- Filters apply immediately and toggle independently with accessible pressed state. Use the
  categories in [12.9](12.9-reader-categories.md) and language selection; omit
  completeness/identifier/edition-count and bibliographic-format pills. Languages combine with OR;
  availability combines with AND and must match the same edition as language. Reset accumulated
  results on search/filter change. Measure responsive grid/viewport for an initial screen of cards;
  append another screen when the bottom sentinel enters view. Keep loaded cards during requests,
  deduplicate work IDs, prevent overlapping loads, and stop at the last cursor. Errors retain
  earlier cards and offer retry; provide a Load more fallback. Resize changes the next batch size
  without discarding loaded results. API batch limit is 1–40 (default 20). Available to read
  requires an approved ready asset; see [12.8](12.8-reading-assets.md). Metadata existence, ebook
  format, or an Open Library record never implies readable content.
- Return one result per work with title, author links and a cover fallback, without requiring a
  LibraryItem or reading progress. Use a localized unknown-author label when credits are missing.
- Debounce typing, cancel superseded requests, cap input/page sizes, and preserve query/filter/page
  navigation state, including accumulated pages and a visible-card scroll anchor on return from
  details. Show loading, no results, retryable failure, and offline states separately.
- `/app/explore/books/[workId]`: localized work metadata, author links, a representative edition
  summary and a link to edition details. Read/Listen use that selected edition. Edition controls
  belong to the separate edition route. App navigation remains usable while details load. Work and
  edition info derive page/time estimates from the processed public copy. Missing counts show
  Unknown; personal minutes/progress are excluded. Unpublished estimates require admin access.
  Representative editions are not necessarily first editions.
- `/app/explore/editions/[editionId]`: public edition metadata/credits, admin edition controls, and
  a back link to its owning work. Generic shell/cache behavior matches work details.
- `/app/explore/authors/[authorId]`: name, biography, and accumulated credited works with Load more.
  Hide source aliases; show safe HTTP(S) biography references as localized Source links. Author
  details have an independent loading boundary; app navigation remains usable during loading.
  Identify contributor roles; edition-only credits must not become work authorship.
- Private uploaded copies and their catalog links stay on `/app/library/books/[slug]`.

Never fabricate copy IDs for catalog payloads.

Keep owned-copy statistics, annotations, offline saving, completion, deletion, and collections in
Library wrappers. Catalog pages never subscribe to copy-specific state. Share metadata formatters;
personal minutes-read composition stays in Library. Preserve description sanitization and existing
reader-link interception.

| Section          | First version: supported catalog data                                     | Later enrichment requiring ingestion/model work  |
| ---------------- | ------------------------------------------------------------------------- | ------------------------------------------------ |
| Header           | Localized title, original title when different, author links              | Subtitle, alternate titles                       |
| About the book   | Description, original language when known                                 | Subjects/genres, series, first publication date  |
| Selected edition | Title, language, publisher, publication year, format, ISBNs               | Exact date, source page count, edition statement |
| Contributors     | Ordered names, roles, credited-as names                                   | Additional structured contributor types          |
| Author page      | Name, biography, source links, credited works                             | Portrait, life dates, external links             |
| Cover            | Work cover, otherwise earliest dated edition with a cover                 | Dedicated asset storage/CDN delivery             |
| About this data  | Add safe source attribution links and metadata update date to public DTOs | Field-level assertions and correction UI         |

Use UI locale, then English, then an available text (including undetermined-language imports), then
original title. Do not label this fallback as the book's language or auto-translate metadata.
Description language pills list only nonempty descriptions; default to UI locale, base locale,
English, then the first available. Identify known description languages; omit a sole unspecified
language. For multiple descriptions, retain language pills, including unspecified; switching changes
only the description. Omit empty description and edition sections; retain edition loading/error
feedback without an empty heading. Do not display UNKNOWN as a publication format. Publication year
belongs to the selected edition, not the work's first release. Separate future publisher page counts
from AVA's estimated content pages and reading-time estimates. Keep bibliographic edition format
separate from the user's uploaded file format. Edition cards show language/publisher/year/format;
load bounded pages on request. Store complete provider-neutral cover URLs on works/editions;
adapters resolve provider IDs. Explore introduction explains wish-list discovery and free
public-domain reading in every locale. No reviews, ratings, sales links, or free-reading badges
without supporting data and behavior.

## Bounded browsing

Errors offer Retry; an empty result does not claim the end of an existing list.

Render visible responsive rows plus two overscan rows on each side; keep the focused row mounted.
Keep five result pages, with one temporary extra page when focus prevents eviction; pause automatic
paging at that bound. Fetch earlier pages through a before cursor. Evict distant pages and preserve
a stable work/row anchor on append, prepend, resize, and return from details. Navigation snapshots
share these bounds and expire after 30 minutes; persisted public response caching remains capped at
40 entries.

## Personal actions: subsequent milestone

Implement [12.2](12.2-personal-library.md) before enabling saves or attachment controls:

- Add to reading list and Add to wish list are independent, persistent memberships without a file.
- Upload EPUB attaches a new private copy to the work and confirmed edition. Link existing upload
  opens only the current user's copies; the existing library page offers the inverse link action.
- Owned-copy section offers Read/Continue, or a copy chooser when several copies exist. Read opens a
  ready copy; uploaded/processing/failed states give accurate status. Catalog metadata alone never
  produces a reader link. Future public reading requires an approved asset and processing pipeline.
- Main API/buckets own personal status and mutations; obtain batched status for visible work IDs,
  not one main-API request per result. Public catalog responses contain no personal status.
- Linked library pages retain file metadata and reading state, with a distinct catalog-details
  section; metadata refresh must not overwrite private import metadata or estimated reading data.

## API, caching, and offline boundaries

Catalog API exposes `GET /api/works?query&languages&filters&cursor&before&limit` with compact cards.
Search title variants, author names/aliases, and normalized ISBNs using indexed PostgreSQL; Filter
language on the matched edition; apply [12.4](12.4-rollout-and-search.md) benchmark gates. Initial
browse/search queries canonical tables with indexed case-insensitive substring matching and exact
normalized ISBN lookup; UUID cursor order is stable, not relevance-ranked. Bound input, page size,
language selections, and DB statement time. Rebuildable projections and relevance ranking remain the
next scaling milestone; no claim of global-corpus performance is made.

Use a dedicated catalog client/base URL and gateway/CORS configuration; browser discovery requests
bypass main API. Production uses same-origin `/catalog/api`; the gateway strips `/catalog`. Cache
public responses in per-user Dexie meta: at most 40 entries, 512,000 characters per entry; SW
bypasses `/catalog/api/*`; no whole-catalog sync. `/api/works/filters` returns ≤200 language codes.
Saved snapshots and personal mutations stay in the per-user library bucket. Include new caches in
identity cleanup; cached content refreshes silently; failures retain retry feedback. Book detail
routes follow existing shell/hydration conventions; uncached offline pages show a useful unavailable
state. Catalog outages must not prevent opening existing library copies.
