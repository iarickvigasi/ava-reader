# Canonical book translations

> Implementation candidate · 2026-09-29 · Parent: [\_overview](_overview.md)

Accepted PDF conversions and validated AVA EPUB imports use the existing translation service and
demand budget. Both load the owned canonical reader with compiled schema/build capability headers.
Neither is reparsed through the legacy EPUB path after acceptance.

## Identity and authority

PDF authority binds its operation/publication; reimported EPUB authority separately binds its owned
import, uploaded-source hash and accepted-reader hash. Reimport mints a new final identity and does
not import the original owner, job or publication authority.

The translation revision is the immutable `final_content_id`. Sentence IDs hash that revision,
chapter and exact source unit, including its block/cell ID and UTF-16 offsets. Source language
comes from accepted source metadata; changing display title, authors or language cannot change
sentence segmentation or reuse another content revision's translations. Chapter ordering comes
from the accepted canonical graph. Table cells and nested list items retain independent IDs.

Translation and alignment writes recheck owned publication/qualification inside an item-locked
transaction, before writes and before commit. A deleted book or revoked qualification refuses
late writes. A request already sent to a provider cannot be unsent; this check controls persistence.
The final response also rechecks authority. Ordinary EPUB translations retain their existing path.

## Presentation and cache

The source pane retains typed source inline styles, references, list nesting/markers, table header
relationships, captions, literal verse and code. Translation text retains the enclosing block
presentation; this implementation does not infer translated-word emphasis from source offsets.
Code and separators are literal units and never sent for AI translation. Images appear on both
sides without a translation request. Short verse is translated per nonblank source line; line gaps and indentation are retained
between translated lines. This preserves its line structure without claiming word alignment.

Partial table ranges retain the table grid and source header context. Repeated header context is
not an extra source locator or a generated translation. Geometry is measured with that same grid;
actual large-table and narrow-device acceptance remains a required test, not established by HTML.
Notes keep their return controls in measured geometry. Session Back settles only when the exact
source fragment is visibly inside the page, including a cold target; page turns do not add history.

A canonical reader supplies its expected final revision to the existing account-scoped cache.
Mismatched cached/network chapters are refused, replaced bucket requests abort, and the complete
catalog is checked against the exact source leaf text/order before display or further demand.
Only source offsets are progress/highlight anchors. Translated selections carry their separate
revision/sentence coordinates; selecting copied code keeps original source coordinates.
