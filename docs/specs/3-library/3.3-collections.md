## Summary
Collections group books into CUSTOM or SMART lists. SMART shelves are system-owned and derived;
CUSTOM lists are user-managed.

## Behaviour
1. Three SMART defaults — Imported Books, Public Domain, Offline Books
   ([[4.8-offline-books-collection]]) — are upserted (keyed by per-user smartKey) whenever a book
   is added to the library; their names/slugs resolve uniqueness against non-smart namesakes.
2. Adding a book joins it to the smart shelf matching its source (IMPORTED → Imported Books,
   CATALOG → Public Domain); membership upserts are idempotent. Offline Books membership mirrors
   offlineRequested in the same transaction ([[4.8-offline-books-collection]]).
3. Rename (PATCH /library/collections/:id) requires a non-empty name, normalizes the description
   (trim; empty → null; omitted → unchanged), 400s on a duplicate name, and is forbidden (403)
   for SMART shelves.
4. Delete (DELETE /library/collections/:id) is forbidden (403) for SMART shelves — they would be
   recreated on the next import and only flicker out and back.
5. Create (POST /library/collections) creates an owned CUSTOM collection with a unique slug and no books.
   Create and edit trim field edges and capitalize the first letter, preserving remaining text.
   Title is required (maximum 100 characters); description is optional (maximum 1,000; blank → null).
   Both reject case-insensitive duplicate titles within the user's collections. Serializable
   transactions retry concurrent write conflicts. Existing case-only duplicates are left unchanged.
   The UI reuses the localized edit form. Clicking New collection offline opens the existing offline
   dialog; losing connection in the form displays an inline message and preserves the draft.
   Successful creation updates the library cache; empty custom collections remain visible without books.
6. A collection page reads by id or slug ([[3.5-library-payloads]]).

## Edge cases
A book in multiple collections; a deleted collection leaves its books in the library; empty
collection states.

## Acceptance criteria
- [ ] Renaming/deleting a CUSTOM collection persists and survives reload.
- [ ] SMART shelves refuse rename and delete with a 403, in the UI and the API.

## Open questions
Add/remove membership and reorder have no endpoints yet — smart membership and the
offline shelf are the only server-side membership writers today.
