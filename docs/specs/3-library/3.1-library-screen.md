## Behaviour

1. Library distinguishes active books without custom memberships from custom collections. The
   general books grid is not a stored collection. Hide it when every book is organized.
2. With no collections, every active book appears directly in the general grid. Progressively reveal
   cards; do not limit the list to the old four-book collection preview.
3. Collections expose every member, retain View all, and sort books by engagement recency. Empty
   custom collections remain available.
4. Adding a book to its first collection removes it from the general grid immediately; removing its
   last membership or deleting its last collection returns it. Multiple memberships are valid.
5. Books counts every active LibraryItem once; Collections counts custom collections only.
6. Import and catalog acquisition add books directly to Library. Existing custom memberships survive
   repeated acquisition. The page refreshes through the library bucket.
7. Preserve existing header actions, import feedback, card navigation, and zero-book guidance.
8. Metadata and membership edits remain offline-first. A local cache upgrade deletes retired default
   shelves; their books remain available in Library. Offline-save flags and content are independent
   of collection organization. Removed default collection links lead back to Library.
9. Book results show reading completion rounded to a percentage, including 0% and 100%.

## Filters

Seven independently toggleable pills: Offline, Imported, Public domain, Wish list, In progress,
Done, Not started. Selection is URL-backed and updates cached results immediately without an Apply
action or a network request. Selections within the source group OR together, as do selections within
the progress group; those groups AND together, with Offline as an additional constraint. No
selections shows everything.

- Offline: content is available on this device, matching the reader's cached-content check; a queued
  download alone does not qualify. Automatically cached reading content does qualify.
- Imported: source IMPORTED. Public domain: source CATALOG with a readable AVA edition.
- Wish list: source CATALOG without a readable AVA edition. The pill ships now; metadata-only
  Explore saving remains deferred ([[12-explore-catalog/12.2-personal-library]]).
- Done: progress >=100 OR an explicit finish date. In progress: progress >0 and <100, not Done.
- Not started: progress exactly 0 and no explicit finish date. A finish date overrides percentage,
  so a manually finished book appears only in Done, including at zero or partial progress.

Filter both general books and complete collection membership; show every matching collection book.
Show matching unassigned books and only collections containing matching books. Hide collections with
no matches while filtering, even when they contain other books; retain empty custom sections when
filters are clear. Keep header totals library-wide. A dedicated no-results message distinguishes
filters from an empty Library. The localized no-results state is shared with Explore. Pending
finish/progress edits and completed or evicted downloads update results immediately. Book
provenance/readability are cached with metadata; legacy unknown provenance never guesses a source,
and stays visible with no source filter. Filter selection survives refresh and navigation.

## Data & sync

GET /library supplies every active book card independently of collections, complete owned item
identities for safe pruning, and custom collection membership/completion snapshots plus previews.
The bucket derives the general list from complete membership evidence overlaid with pending edits.
Cached metadata must work with zero collections, including a previously hydrated empty Library. The
primer enumerates the required books array in the normalized Library view. Dexie v6 removes retired
collections before cache reads, so consumers do not need legacy-shelf hiding filters.
